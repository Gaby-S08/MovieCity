## `01` — Sobre o projeto

O **MovieCity** é uma Landing Page de filmes desenvolvida para colocar em prática os fundamentos do React. O projeto apresenta uma interface moderna, inspirada no universo do cinema, com uma identidade visual em tons de azul.

A proposta é oferecer uma experiência agradável para explorar filmes, conhecer títulos e navegar por um catálogo visual.

> 🎞️ Cada filme tem uma história. Encontre a sua próxima favorita no MovieCity.

## `02` — Funcionalidades

| Recurso | Descrição |
|---|---|
| 🎬 Catálogo | Exibição de filmes em cards |
| 🔎 Pesquisa | Busca de títulos |
| 🏷️ Categorias | Filtros para explorar filmes |
| 💙 Favoritos | Lista de filmes favoritos |
| 📱 Responsividade | Layout adaptável a diferentes telas |

## `05` — Como executar

**1. Clone o repositório**

```bash
git clone https://github.com/SEU-USUARIO/MovieCity.git
```

**2. Entre na pasta do projeto**

```bash
cd MovieCity
```

**3. Instale as dependências**

```bash
npm install
```

**4. Inicie o servidor de desenvolvimento**

```bash
npm run dev
```

**5. Para testar a compilação**

```bash
npm run build
```
